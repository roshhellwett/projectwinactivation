# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within projectwinactivation, please follow these guidelines:

### How to Report

1. **Do NOT** create a public GitHub issue for security vulnerabilities
2. Instead, send an email to: roshhellwett@icloud.com
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce the issue
   - Potential impact of the vulnerability
   - Any suggested fixes (if applicable)

### What to Expect

- **Response Time:** We aim to respond within 48 hours
- **Initial Assessment:** We will assess the vulnerability and severity
- **Updates:** We will keep you updated on our progress
- **Credit:** If you wish, we will credit you in the release notes

### Scope

This security policy applies to:
- The main projectwinactivation package
- All official submodules and utilities
- The CLI interface and all menu options

### Out of Scope

- Social engineering attacks
- Physical security issues
- Denial of service attacks against third-party services
- Vulnerabilities in dependencies (please report to their maintainers)

## Security Best Practices

When using projectwinactivation:

1. **Administrator Privileges:** Some features require admin rights - use responsibly
2. **Windows Activation:** Use only on systems you own or have license for
3. **Service Management:** Be cautious when starting/stopping services
4. **Process Termination:** Ensure you don't kill critical system processes

## Version Support

We provide security updates for the latest stable release. We recommend keeping your installation up to date.
